### 2. Square of First N Numbers Starting from S

Accept two values **S** and **N** from the user and print the square of the first **N numbers** starting from **S**.

**Example:**

```text
Enter S: 3
Enter N: 5

Output:
9
16
25
36
49
```

---

### 3. Reverse an Accepted String

Accept a string from the user and print the string in reverse order.

**Example:**

```text
Input:  Python

Output: nohtyP
```

---

### 4. Count Vowels in a Sentence

Accept a sentence from the user and count the total number of vowels present in it.

**Vowels:**

```text
a, e, i, o, u
```

**Example:**

```text
Input: Python Programming

Output: Number of vowels = 4
```

---

### 5. Remove Duplicate Elements from a List

Write a Python program to remove duplicate elements from a list.

**Example:**

Original List:

```python
[23, 34, 23, 37, 48, 89]
```

List after removing duplicates:

```python
[23, 34, 37, 48, 89]
```

---

### 6. Reverse a List

Write a Python program to reverse the elements of a list.

**Example:**

Original List:

```python
[23, 34, 37, 48, 89]
```

Reversed List:

```python
[89, 48, 37, 34, 23]
```
